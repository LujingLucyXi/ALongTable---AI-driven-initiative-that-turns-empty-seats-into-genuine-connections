# ALongTable prototypes

Static prototypes for both sides of the ALongTable booking experience:

- `ALongTable.glomere.tech/` — C-end theme discovery, populated tables, prepaid menu selection, seat selection, checkout, and booking confirmation.
- `ALongPartner.glomere.tech/` — restaurant partner dashboard for off-peak recommendations, prix fixe menus, auto-adjustment controls, and sample C-end orders.

Open each folder's `index.html` to view its prototype.
