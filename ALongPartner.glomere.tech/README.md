# ALongPartner.glomere.tech prototype

Restaurant partner console for managing AI-recommended off-peak prix fixe offers and viewing prepaid C-end bookings.

## Included flows

- Review AI suggestions for quiet time windows, per-guest discount, and expected table fill.
- Publish or pause an off-peak offer for C-end discovery.
- Choose restaurant dishes for starter, main, and dessert courses.
- Toggle automatic availability, price, and timing adjustments.
- Review sample prepaid C-end bookings, including guest count, table seats, selected dishes, and total paid.

This is a static prototype with in-page state and sample orders. A production version needs a shared booking service to deliver real C-end bookings to the partner inbox.
